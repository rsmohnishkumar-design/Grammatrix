# Design preference

When building UI for this project (or asked to reuse this style elsewhere), default to a dark, neon "cyber/gaming" look:

- Background: near-black / dark navy (e.g. `#0a0a12`–`#12121e`), not white or light gray.
- Accent colors: vivid gradients — pink/magenta → orange, and cyan/teal → blue — used on buttons, borders, icons, and glowing highlights.
- Typography: bold, wide, tech/display-style headings (uppercase, letter-spaced) paired with a clean sans-serif for body text.
- Cards/panels: dark surfaces with a subtle border glow or gradient outline, rounded corners, soft shadow.
- Buttons: solid gradient fills (pink→orange or cyan→blue) rather than flat single colors.

Reference: a "Dominion — Cyber Empire" clicker-game dashboard the user shared (dark background, pink/orange and cyan gradients, bold uppercase headings, glowing circular action button) is the target aesthetic.
